## Forgetax Demo Problems and Community-Reported Fixes

Player experience reports cluster around a handful of recurring issues. Try these in order before you assume the game is broken.

| Symptom | Likely cause | Fix to try |
|---|---|---|
| Game won't launch | Missing runtime or outdated drivers | Update GPU drivers and OS, then verify game files |
| Black screen on startup | Display mode conflict | Force windowed mode via launch options or config file |
| Controller not detected | Input API mismatch | Enable the correct input setting in Steam or the launcher |
| Heavy stutter | Shader compilation or background apps | Close overlays, let the game warm up, cap frame rate |
| Demo expired | Time-limited build | Check the developer's channels for a re-release window |
| Save won't load | Version mismatch after an update | Start a fresh save; demo saves rarely migrate |

One more piece of community wisdom worth repeating: **if the demo crashes on a specific action, report it.** Developers actively read demo feedback because the whole point of a public demo is to catch problems before launch. A short report with your specs, the exact action, and a screenshot is genuinely useful.
