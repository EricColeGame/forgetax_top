### Was eine Demo ist – und was nicht

Eine Demo ist ein kuratierter Ausschnitt, keine Beta. Sie ist auf einen bestimmten Standard poliert, auf eine bestimmte Länge zugeschnitten und so gestaltet, dass sie in einem Moment endet, der Lust auf mehr macht. Diesen Unterschied zu verstehen, hält Ihre Erwartungen kalibriert und macht Ihr Feedback für das Team weit nützlicher.

- **Sie ist:** ein repräsentativer Vertical Slice der Core Loop.
- **Sie ist nicht:** das vollständige Spiel mit einem Schloss davor.
- **Sie ist:** in der Regel funktionsvollständig für die Systeme, die sie zeigt.
- **Sie ist nicht:** ein Versprechen, dass jedes System aus der Demo unverändert erscheint.

## Forgetax Demo-Release vs. vollständiger Launch: Was üblicherweise übernommen wird

Eine der häufigsten Fragen rund um jede Demo ist einfach: Überlebt mein Fortschritt? Die Antwort hängt vollständig davon ab, wie das Studio sie gebaut hat, aber die folgende Tabelle deckt die typischen Ergebnisse ab.

| Funktion | Typisches Demo-Verhalten | Typisches Launch-Verhalten |
|---|---|---|
| Story-Fortschritt | Wird oft übertragen, wenn die Demo ein Prolog ist | Wird aus Ihrem Spielstand fortgesetzt |
| Charakter-Verbesserungen | Manchmal begrenzt oder zum Balancing zurückgesetzt | Vollständiger Progressionsbaum freigeschaltet |

| Einstellungen und Tastenbelegung | Bleiben erhalten, wenn das vollständige Spiel die Demo erkennt | Werden automatisch übernommen |
| Inhaltsumfang | Ein Ausschnitt | Vollständiges Spiel |

Community-Berichte von Demo-Spielern aus der gesamten Branche weisen konsequent darauf hin, dass Prolog-Demos sauber übertragen werden, Vertical Slices hingegen nicht. ## Eine praktische Einrichtungs-Checkliste für Ihre erste Session

Demos sind oft weniger optimiert als der finale Build, daher bringt ein wenig Einrichtung viel. Nutzen Sie diese Checkliste als schnellen Durchgang vor Ihrem ersten Run.

| Einstellung | Empfohlener Ausgangspunkt | Hinweise |
|---|---|---|
| Auflösung | Native Bildschirmauflösung | Auf 1080p heruntergehen, wenn die Bildrate leidet |
| Bildratenbegrenzung | Auf die Bildwiederholrate Ihres Monitors abstimmen | Reduziert Spulenfiepen und Hitze |
| V-Sync | Anfangs aus, an bei sichtbarem Tearing | Fügt bei Aktivierung leichte Eingabelatenz hinzu |
| Sichtfeld | Eine Stufe über den Standard erhöhen | Hilft beim Bewegungskomfort |
| Untertitel | An | Demos mischen Audio in frühen Builds oft schlecht ab |
| Bewegungsunschärfe | Aus | Erleichtert die Beurteilung der visuellen Klarheit |
| Tastenbelegung | Belegen Sie neu, bevor Sie die Steuerung beurteilen | Standardbelegungen sind selten final |

Spielen Sie mindestens dreißig Minuten, bevor Sie sich eine Meinung bilden. Eröffnungssequenzen sind der am stärksten gescriptete Teil jeder Demo und am wenigsten repräsentativ für die Moment-zu-Moment-Loop.

### Worauf Sie beim Spielen achten sollten

- **Reaktionsfähigkeit:** Fühlt sich die Eingabe unmittelbar an, oder gibt es eine merkliche Verzögerung?
- **Lesbarkeit:** Können Sie erkennen, was interaktiv ist, ohne alles abzufahren?
- **Pacing:** Respektiert die Demo Ihre Zeit, oder streckt sie ihre Laufzeit künstlich?
- **Stabilität:** Jedes Ruckeln, jeder Absturz oder Audio-Aussetzer ist es wert, mit Ihren Hardware-Spezifikationen protokolliert zu werden.
- **Klarheit des Ziels:** Wissen Sie jederzeit, was Sie tun sollen?

## Wie Sie Feedback geben, das das Spiel tatsächlich mitgestaltet

Feedback ist der Bereich, in dem Spieler echten Einfluss haben, und die forgetax Demo-Release ist darauf ausgelegt, es zu sammeln. Der Unterschied zwischen nützlichem und nutzlosem Feedback liegt in der Spezifität. „Es fühlte sich schlecht an" sagt einem Entwickler nichts. „Der Ausweich-Input wurde etwa eine halbe Sekunde registriert, nachdem ich die Taste auf einem kabelgebundenen Controller gedrückt hatte" gibt ihm etwas, das es reproduzieren und beheben kann.

| Feedback-Typ | Schwache Version | Starke Version |
|---|---|---|
| Performance | „Es laggt" | „Framedrops in die niedrigen 40er im überfüllten Marktbereich auf einer Mittelklasse-GPU" |
| Steuerung | „Steuerung ist seltsam" | „Kameraempfindlichkeit fühlt sich im Standard zu hoch an; Zielassistenz springt über Ziele hinaus" |
| Schwierigkeit | „Zu schwer" | „Die zweite Begegnung hat kein sicheres Zeitfenster zum Heilen zwischen den Wellen" |
| UI | „Verwirrendes Menü" | „Ich konnte den Inventar-Tab nicht finden, ohne zuerst die Karte zu öffnen" |
| Bugs | „Es ist abgestürzt" | „Absturz beim Laden nach Alt-Tab; zweimal in fünf Versuchen aufgetreten" |

Geben Sie immer Ihre Plattform, Hardware und Build-Kennung an, falls eine im Hauptmenü angezeigt wird. Reproduzierbarkeit ist die Währung von Bug-Reports.
